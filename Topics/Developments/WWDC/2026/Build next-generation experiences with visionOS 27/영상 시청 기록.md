## 세션 소개

visionOS 27로 앱·게임·공간 경험을 만드는 방법을 훑는 개괄 세션. 플랫폼에 들어오는 **세 갈래 경로**를 정리하고, RealityKit·Reality Composer Pro 3의 신기능, 서드파티 엔진 지원, 그리고 macOS/PC 콘텐츠를 비전프로로 끌어오는 새 프레임워크(Spatial Preview, Foveated Streaming)를 소개한다. 발표자는 Vision Products Group의 디렉터 Norman.

# 내용 정리

## 2:00 · visionOS overview

최신 Apple Vision Pro는 **M5 칩**. 눈당 4K 이상 픽셀, 손 추적 **90Hz**.

## 3:13 · Paths to build a visionOS experience

플랫폼에 들어오는 길이 **세 갈래**다.

**1. 기존 iOS/iPadOS 앱** — 이미 iPad·iPhone에서 도는 앱이면 거의 그대로 올라간다.

- **Compatibility 모드**: App Store Connect에서 체크박스 하나. 가장 빠른 진입.
- **재컴파일**: Xcode 설정에 visionOS를 deployment target으로 추가.

**2. 공간 컴퓨팅용으로 처음부터 설계한 앱** — 사용자의 실제 환경과 섞이고 반응한다.

- 네이티브: **SwiftUI + RealityKit + Reality Composer Pro**, 또는 커스텀 렌더링 엔진 + **CompositorServices**
- 서드파티 엔진: **Unity, Unreal, Godot** 모두 visionOS를 플랫폼으로 지원

**3. (신규) 기존 macOS/PC 경험 가져오기**

- **Spatial Preview framework** — Mac에서 이미지·문서·3D 콘텐츠를 비전프로로 확장. **visionOS 앱을 안 만들어도 된다.**
- **Foveated Streaming framework** — PC의 3D 경험을 스트리밍. 네이티브 콘텐츠와 스트리밍 콘텐츠를 **같이** 띄울 수 있다.
  - 예시: 비행 시뮬레이터에서 정교한 콕핏은 RealityKit으로 네이티브 렌더, 프로세서를 많이 먹는 지형은 원격 컴퓨터에서 스트리밍.

## 6:39 · RealityKit and Reality Composer Pro

> "RealityKit is the rendering engine behind some of the best native experiences on visionOS."

### RealityKit 신기능

**Physical Space Lighting** — 가상 조명을 실제 공간의 빛과 섞는다.

- **Projective Textures API**: 스포트라이트에 텍스처를 입힌다. 스테인드글라스 투영, 수중 커스틱 같은 효과.

**Cloth Simulation** — 실시간 천 시뮬레이션. 마네킹이 걸으면 드레스가 자연스럽게 접히고 흔들린다.

**Custom Reverb Mesh** — 공간 오디오의 사실성. 나무·금속·돌이 소리를 어떻게 흡수하고 산란시키는지 정확히 시뮬레이션한다. 소리가 앞에서만 나는 게 아니라 사방에서 공간을 채운다.

**Gaussian Splatting** — 실제 물체를 스캔해서 3D 가우시안 스플랫으로 렌더. 화분 흙 질감까지 살아난다.

### Reality Composer Pro 3 (대규모 개편)

> "so you can move faster and go further, **without always needing to touch Xcode**."

- **RCP Assistant (AI)** — 원하는 걸 말로 설명하면 텍스처·머티리얼까지 갖춘 3D 모델을 생성해 씬에 배치. 데모에서 빈 그릇에 말린 과일 모듬을 생성해 넣고, 테이블에 초까지 만들어 올렸다.
- **Animation Graph** — 상태 머신으로 애니메이션 전환 제어 (idle ↔ walking). 에디터에서 라이브로 확인.
- **Navigation Meshes** — 캐릭터가 장애물을 피해 이동하도록 내비메시를 RCP 안에서 생성·수정. 자동 생성 후 점프·사다리·장애물 추가.
- **Script Graph** — 노드 기반 로직. 탭 같은 이벤트를 잡아 캐릭터 이동을 구동. **Xcode 없이** 비전프로에서 라이브 프리뷰로 실시간 편집.
- **Shader Graph 강화** — **subsurface scattering** 노출. 사실적인 피부·눈·머리카락, 포탈 같은 이질적인 룩까지.
- 그 외: Prototypes, Behavior Trees, Compute Graphs, 커스텀 script graph 노드

## 13:42 · Third-party game engines

**Unity** — 런칭 때부터 호환. Unity Pro 라이선스 필요. (예: 볼륨에서 도는 LEGO Builder's Journey)

- 윈도우 게임 → **RealityKit**으로 네이티브 렌더
- 몰입형 게임 → **RealityKit 또는 CompositorServices** 중 렌더링 필요에 따라 선택
- PSVR2 Sense 컨트롤러 등 공간 액세서리 플러그인 배포됨

**Unreal Engine** — 몰입 모드 지원. Polyarc의 *Glassbreakers*가 **static foveation**으로 눈에 띄게 선명한 비주얼을 냈다.

**Godot** — Blender Studios의 *DogWalk* 등. **CompositorServices 렌더링 지원** 추가 + RealityKit 렌더링용 플러그인 + **PHASE 오디오 플러그인**.

**커스텀 엔진** — CompositorServices로 자체 엔진을 시스템에 연결해 몰입 공간에 직접 렌더.

> 플러그인은 Apple GitHub 페이지에서 다운로드.

## 15:47 · Spatial Preview

**visionOS 앱을 만들지 않고도** Mac의 공간 콘텐츠를 비전프로에서 미리 보고 **SharePlay로 협업**하는 새 macOS 프레임워크.

- visionOS의 **Quick Look**을 활용. 공간 사진, Apple Immersive Video, USD 3D 콘텐츠를 즉시 프리뷰하고 라이브 편집.
- 3D 씬 안을 자유롭게 돌아다니며 배치 조정, 머티리얼 오버라이드, **주석으로 피드백**.
- Cinema4D, SketchUp 같은 앱과 실시간 에셋 편집 → 원격 협업 3D 워크플로.
- **macOS 27의 Preview 앱에 기본 내장.** Preview에 3D 편집 도구도 새로 들어간다.

## 17:28 · Foveated Streaming

PC 등 외부 기기에 접속해 **OpenXR 콘텐츠를 스트리밍**한다. visionOS가 손·컨트롤러 위치·마이크 같은 입력을 자동으로 보내고, 기기는 비디오·오디오를 풀 몰입으로 스트리밍한다. **visionOS 26.4에 이미 출시됨.**

**핵심 기술 — 시선 기반 압축**: 보고 있는 영역은 고품질로, 주변시 영역은 대역폭을 적게. 너무 빠르고 매끄러워서 알아채지 못한다.

**프로토콜은 NVIDIA CloudXR.** Wi-Fi만으로 충분한 성능. 동글·케이블 불필요. 로컬 PC든 클라우드 인스턴스든.

**사례**

- **X-Plane 12** (Laminar Research) — visionOS 앱이 ARKit으로 내 공간과 장비를 인식하고, 시뮬레이션은 PC에서 스트리밍. 실물 플라이트 시뮬레이터를 조작하면서 가상 세계에 완전히 몰입.
- **iRacing** — iRacing Connect 앱이 실물 레이싱 휠 위치와 가상 콕핏을 맞춘다. ARKit의 정밀 추적이 가능하게 함.
- **Autodesk VRED** (Innoactive) — 레이트레이싱 대형 모델을 1:1 스케일로. PC 렌더링 + SwiftUI 조합.

> "하루면 OpenXR 앱 스트리밍을 시작할 수 있고, 일주일이면 visionOS에만 있는 기능으로 확장할 수 있다."

## 20:36 · Object tracking and spatial accessories

### 오브젝트 트래킹

**기존 흐름 (visionOS 2.0~)**: USDZ 모델 → Mac의 **Create ML**에서 reference object 학습 → object tracking API에 전달 → 앱이 실물의 위치·방향 업데이트를 받음.

**visionOS 27 신규**

1. **고프레임레이트 트래킹** — 물체가 움직일 때 포즈 업데이트가 더 자주 온다
2. **Create ML의 extended training** 옵션 — 정확도·강건성 향상, 특히 **손에 든 물체**
3. **metric space 포즈 API** — 디스플레이 보정 없는 포즈. 고정밀이 필요한 **공간 측정** 용도
4. **iOS에서도 사용 가능** — ARKit API로 동일 기능 제공. Create ML 학습이 플랫폼 독립적이라 **reference object 하나를 iOS·visionOS 양쪽에서** 같은 품질로 재사용

사례: 의료용 프로브 같은 핸드헬드 도구로 실제 공간을 정밀 추적·측정 → **수술 내비게이션 훈련**.

### 공간 액세서리

**visionOS 26**: Logitech Muse, PSVR2 Sense 컨트롤러. **Game Controller framework**로 연결하고, RealityKit이나 ARKit으로 공간상 움직임·방향을 추적.

**visionOS 27 — 직접 만들 수 있다.** 필요한 부품:

- 비전프로가 볼 수 있는 **LED 성좌(constellation)** — 추적용
- **IMU** — 방향·가속도
- **Bluetooth 칩** — 신호 전송
- (선택) 버튼, 터치패드, 햅틱

> 이 부품들을 넣으면 **어떤 물체든** 공간 액세서리가 된다. DFRobot, MikroE가 레퍼런스 하드웨어와 개발 키트를 연내 출시 예정.

**데모**

- 3D 프린팅 손전등 + DFRobot seeMote Cap → 가상 빛이 실제 벽에 자연스럽게 비친다. 저지연 추적 덕에 빔이 부드럽게 따라온다.
- 실물 스티어링 휠 안에 MikroE Spatial Anchor R1 → 디지털 차량이 휠에 앵커링. 휠을 잡으면 차 안에 있는 느낌. 레이싱 시뮬레이션, 차량 인테리어 디자인.

**성능**: 디스플레이 네이티브 리프레시 레이트에 맞춘 최고 주파수 + 극저지연. 빠른 동작 대응, **일시적으로 가려져도** 추적 유지, **저조도**에서도 추적.

## 25:32 · Immersive media

### Apple Immersive Video (AIV)

visionOS에서 가장 높은 충실도의 몰입 비디오. 극도로 넓은 시야각 + 완전 몰입 오디오. **고해상도·고프레임레이트 스테레오 180도 캡처** 기반. VOD와 **라이브 방송** 둘 다 지원.

**스펙**

- 메타데이터 기반 **렌즈 캘리브레이션**으로 실제 스테레오 스케일 유지 → 재생 시 정확한 투영
- **90fps**, 프레임당 **100메가픽셀 이상** (인간 시각 예민도에 근접) → 초당 100억 픽셀 이상

### Immersive Media Support (IMS) 프레임워크

AIV의 리치 메타데이터를 읽고 쓰며, 몰입 콘텐츠 저작·수정을 지원한다. (기존 iOS 지원에 더해) visionOS 27 신규:

- **Set Camera Command Overrides** — 라이브·복잡한 프로덕션에서 기본 카메라 설정을 **실시간으로** 덮어쓴다
- **ImmersivePreviewRenderer API** — 편집·라이브 프로덕션 중에 **Mac에서 비전프로로** AIV를 실시간 프리뷰. 에디터·컬러리스트·감독이 최종 결과물을 정확히 확인
- **와이드 종횡비 포탈 지원** — 완전 몰입 → 포탈 모드로 전환할 때 매우 넓은 포탈을 유지. AVKit은 `AVPlayerViewController`, RealityKit은 `VideoPlayerComponent`에서 커스텀 종횡비 설정

### 스트리밍용 Static Foveation

풀 해상도 AIV를 스테레오 90fps로 스트리밍하는 건 고속 가정용 인터넷으로도 비현실적이다. 그렇다고 **4K로 그냥 줄이면 픽셀 밀도를 너무 잃는다.** 대신 인코딩 전에 **부드러운 static foveation 함수**를 이미지에 적용한다 → 스트리밍 가능한 프레임 크기에서 고해상도 몰입 비디오. 샘플 프로젝트로 시연.

### ASAF Production Suite

AAX 플러그인 모음 업데이트. 레퍼런스 비디오 기준으로 오브젝트 배치, 앰비소닉 워크플로 개선(**Scene Compressor** 플러그인 신규), 히트맵 드로잉·공간 필터링 알고리즘 향상.

> 샘플 프로젝트와 ASAF Production Suite 모두 developer.apple.com에서 다운로드.

## 30:46 · Other visionOS 27 updates

- **Safari** — 창을 더 넓은 종횡비로 조절 가능. 큰 창은 자연스럽게 **곡면**으로 휘어 시야에 들어온다. **Web Environments가 기본 활성화** — 웹사이트도 앱처럼 배경 환경을 가진다 (데모: Apple TV 시리즈 *Severance* 환경)
- **Control Center 개선** — 알림·시스템 상태·컨트롤·환경을 한 곳에
- **High Quality Capture** — Mac 없이 비전프로에서 바로 **4K**로 앱 캡처
- **Accessory widget 지원** — 작고 한눈에 보는 위젯으로 앱 확장
- 그 외: Siri 개선, 새 **Iceland** 환경, Spatial Panoramas, Personal Environments, Freeform 업데이트
